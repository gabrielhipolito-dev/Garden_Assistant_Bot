# Contributing

Thanks for your interest in contributing!

## Getting started

1. Fork the repository and create your branch from `main`.
2. Keep changes focused and include clear descriptions in your PR.
3. Update documentation when you change behavior or project structure.

## Development notes

- The desktop app builds on Windows with Visual Studio 2022 and .NET 8.
- Firmware changes should be validated on real hardware.

## Pull request checklist

- [ ] Code builds successfully.
- [ ] Documentation updated (if applicable).
- [ ] Screenshots updated for UI changes.

## Code of Conduct

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md).
